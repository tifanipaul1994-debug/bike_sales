# 🚴‍♀️ My First Data Project: SQL + Power BI Dashboard

I’m excited to share my first Power BI dashboard, built to analyze the performance of Toman Bike Shop!

![alt image](https://github.com/FatimaZahraa-Harrak/bike_sales/blob/d37d07fa0ea36bb2d6ed97bb352202b074c1ca6d/dashboard_bike.png)

## 🧩 Tools used: SQL + Power BI
### 📊 What I did:

Combined yearly data with SQL (CTE + UNION)

Calculated revenue & profit

Visualized KPIs, trends, and rider behavior in Power BI

### 💡 Key insights:

Revenue: $3M, Profit: $2.29M, Margin: 45%

Midday & Autumn are most profitable

82% of riders are registered users

This project taught me how to turn raw data into insights.
